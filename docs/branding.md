# Branding Overview
This document captures the design decisions and implementation details for the premium Kinertic Media Arts website, matching the visual style of the Instagram account **[kinertic_marketing](https://www.instagram.com/kinertic_marketing/)**.

## Assets
- **Colors** – defined in `src/assets/branding/colors.ts` as `brandColors`. The palette mirrors the dominant hues from the Instagram feed.
- **Fonts** – imported via `src/assets/branding/fonts.css`. Currently uses the Inter family from Google Fonts to approximate the Instagram typography.
- **Logo** – SVG placeholder located at `public/branding/logo.svg` (replace with the final extracted SVG when ready).
- **Image assets** – any hero or decorative images should be placed under `src/assets/branding/` and referenced via `/branding/...` URLs.

## Tailwind Configuration
The Tailwind config now merges the custom palette:
```ts
import type { Config } from 'tailwindcss';
import { brandColors } from './src/assets/branding/colors';

const config: Config = {
  // ...content paths
  theme: {
    extend: {
      colors: { ...brandColors },
      // original Kinertic palette retained via brandColors if needed
    },
  },
  plugins: [],
};
export default config;
```
All components can now use the new color tokens, e.g. `bg-primary`, `text-accent`, etc., according to the keys defined in `brandColors`.

## Component Updates
- **Navbar** – swapped the original SVG icon for the branding logo (`/branding/logo.svg`).
- Global font stack is applied via `app/globals.css` which imports `fonts.css`.
- No other component changes were required; existing classes already leverage the Tailwind palette.

## Verification Steps
1. Run `npm run dev` and confirm the logo appears in the navigation bar.
2. Verify colors throughout the site correspond to the values in `brandColors`.
3. Check that the custom font loads (inspect computed `font-family`).
4. Run `npm run build` – it should complete without errors.
5. Perform a manual responsive check (mobile, tablet, desktop).
